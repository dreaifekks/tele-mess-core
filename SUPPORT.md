# Support

## Usage Questions

Start with the [README](README.md) and the guides in [`docs/`](docs/). If the
documentation does not answer the question, open a
[GitHub issue](https://github.com/dreaifekks/tele-mess-core/issues/new/choose)
using the question template.

Include:

- the `tele-mess-core` version or commit;
- Python version and operating system;
- installation method and runtime mode;
- the exact command or API endpoint involved;
- expected and observed behavior; and
- a minimal, sanitized error excerpt.

Support is provided by maintainers and contributors as time permits; there is
no guaranteed response-time SLA.

## Bugs and Feature Requests

Use the bug or feature request template in the issue chooser. Search existing
issues first and keep one problem or proposal per issue.

## Keep Private Data Out of Issues

Public issues are not a secure support channel. Never post `config.yml`,
Telegram `.session` files, SQLite archives, downloaded media, API tokens, phone
numbers, login codes, 2FA passwords, private message contents, or unredacted
logs. Reproduce problems with synthetic data whenever possible.

For a suspected vulnerability, stop and follow [SECURITY.md](SECURITY.md)
instead of opening a normal issue.
